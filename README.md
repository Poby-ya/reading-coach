# 영어 읽기 코치 (Reading Coach)

https://poby-ya.github.io/reading-coach/

영어 논문·뉴스를 읽다 막힌 문장만 끊어 읽기 해설을 받고, 모은 단어·문장을 간격을 두고 복습하는 브라우저 앱의 배포본입니다. 기록은 쓰는 사람의 브라우저에만 저장되고, Claude API는 각자의 키로 부릅니다.

이 저장소에는 빌드 결과만 있습니다. 영영 뜻은 위키낱말사전(Wiktionary, CC BY-SA)에서 가져옵니다.
